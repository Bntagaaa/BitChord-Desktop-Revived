348b613a0c3db1a54de56483ea6f8748d6465211; no JNI or earlier Flutter bridge copied.
No ONNX/Signalsmith/Automix sources or models are incorporated in this phase.

FFmpeg: https://ffmpeg.org/legal.html, LGPL 2.1-or-later for the Windows
vcpkg configuration used here (no gpl/nonfree/version3 features selected).
Reproducible source recipe: microsoft/vcpkg commit
ef7dbf94b9198bc58f45951adcf1f041fcbc5ea0, ports/ffmpeg (7.1.1#2),
source URL/hash and patches in that pinned port. Dynamic DLLs are copied
unmodified with the vcpkg copyright files. The library remains replaceable.
Linux uses the distribution's FFmpeg shared libraries (Ubuntu 22.04 FFmpeg
4.4 and its distribution build configuration, which may include GPL features).
No codecs or models are downloaded at runtime. Redistribution must include
corresponding dependency source/build information and license requirements.
No binary releases are published by this phase.

libpulse: LGPL 2.1-or-later; alsa-lib: LGPL 2.1-or-later. Linux shared system
libraries; PipeWire is supported through its Pulse-compatible server.
SQLite: public domain, https://sqlite.org/copyright.html.
Windows output uses the Windows SDK WASAPI interfaces. No Java sidecar.

Dart bindings generated by ffigen 20.1.1 (BSD-3-Clause); generator dependencies
are separately pinned in tool/ffi/pubspec.lock, not runtime dependencies.
